# Game Locker

> 专注于 Win 掌机 / 平板的快捷体验

Game Locker 是面向 Windows 掌机与平板的手柄 / 触控优先游戏启动器：把游戏与应用收进磁贴集统一管理，从启动、编辑到设置全程不需要键鼠。

## 特性

- **磁贴集启动**：游戏与应用以磁贴展示，支持翻页、拖拽换位与组合成组
- **手柄全流程操作**：启动、编辑、设置、呼出一只手柄搞定
- **触控 / 鼠标等价操作**：每项手柄操作都有对应的触控或鼠标操作
- **灵活添加**：按 X 添加，或直接把文件拖入窗口
- **侧边栏形态**：左停靠 / 右停靠 / 全屏三种布局，呼出与收起带滑动动画
- **全局呼出**：手柄组合键（按住 1 秒）或屏幕边缘向内滑动，任意应用前台时都能唤出
- **托盘常驻**：不占任务栏、不打断全屏游戏，点托盘图标即可呼出
- **个性化设置**：玻璃效果、背景颜色、窗口透明度；顶栏可显示时钟、电池、网络与手柄状态

## 系统要求

| 项目 | 要求 |
| --- | --- |
| 系统 | Windows 10 10.0.19041 或更高 |
| 架构 | x64 |
| 运行时 | 无需额外安装（自包含，Windows App SDK 运行时已内嵌） |

## 快速开始

1. 到本仓库的 Releases 页面下载 `GameLocker-v*-win-x64.zip`
2. 解压到任意目录
3. 双击运行 `GameLocker.exe`

首次启动后可长按设置磁贴进入设置，按需调整停靠位置、外观与呼出方式。

## 从源码构建

需要 .NET SDK 8；生成 PRI 资源索引还需要 Visual Studio 2022 Build Tools（`GameLocker.csproj` 中的 `AppxMSBuildToolsPath` 会自动指向它）。

```powershell
dotnet build GameLocker.csproj -c Release
```

产物位于 `bin\Release\net8.0-windows10.0.19041.0\win-x64\`。

## 操作说明

### 主页 / 磁贴集

| 手柄 | 触控 / 鼠标 |
| --- | --- |
| 方向键 | 点按磁贴选择 |
| A | 启动 · 展开组 · 切图 · 播放/暂停 |
| Y | 长按磁贴 = 关闭窗口 |
| R3 | 双击磁贴 = 编辑 |
| L3 | 长按设置磁贴 = 编辑模式 |
| X | 文件拖入窗口 = 添加 |
| LB / RB | 翻页 · 上一/下一曲 · 上一/下一张 |
| View | 点设置磁贴进入设置 |
| B | 隐藏托盘（下滑 = 收起） |

### 编辑模式

| 手柄 | 触控 / 鼠标 |
| --- | --- |
| 按住拖动 | 拖到空位 / 磁贴 = 换位 |
| 轻点 | 标记磁贴（青色描边） |
| A / 标记 ≥ 2 | 轻点加号 = 组合成组 |
| Y | 拖到垃圾桶 = 删除 |
| B | 轻点设置磁贴 = 退出 |

### 设置

| 手柄 | 触控 / 鼠标 |
| --- | --- |
| 方向键 / A | 点分类进入 · 点开关调整 |
| B | 返回按钮 · 下滑返回 |

### 全局呼出

| 手柄 | 触控 / 鼠标 |
| --- | --- |
| 组合键 | 按住 1 秒唤出窗口 |
| 全屏组合键 | 按住 1 秒切换全屏 |
| 托盘 / 边缘 | 点托盘图标 · 屏幕边缘内滑 |

## 目录结构

```
GameLocker/
├─ Assets/            图标等资源
├─ Controls/          自定义控件（提示条等）
├─ Models/            数据模型
├─ Services/          手柄、边缘手势、图标、设置等服务
├─ MainPage.xaml       主页磁贴集
├─ TileSetPage.xaml    磁贴集管理 / 编辑
├─ AddItemPage.xaml    添加项目
├─ SettingsPage.xaml   设置入口
├─ GeneralPage.xaml    常规设置
├─ AppearancePage.xaml 外观设置
├─ TopbarPage.xaml     顶栏设置
├─ WidgetPage.xaml     小组件设置
├─ KeybindPage.xaml    控制设置
├─ AboutPage.xaml      关于
└─ ControlHelp.cs      操作对照表
```
