# OptiCaptureHost runtime preview

Local engineering test only. This installer is not a GameLocker update or a public redistribution package. It does not launch a game or install the GameLocker application. Use it only with a verified `-CoreFilesOnly -OfficialScalerArchive` runtime directory.

- OptiCaptureHost 2.10.80 (GPL-3.0): [pinned source tag](https://github.com/tegraultra/OptiCaptureHost/tree/v2.10.80) and [third-party notice](https://github.com/tegraultra/OptiCaptureHost/blob/v2.10.80/NOTICE.md).
- OptiScaler v0.1.39 (GPL-3.0): [pinned source tag](https://github.com/janblade/OptiScaler-F5-DLSSNR-Multipass/tree/v0.1.39). The archive's `OptiScaler.dll` is installed as `dxgi.dll` without binary changes.
- Intel XeFG and XeLL: original signed binaries. See the Intel license included in the `Licenses` folder. The preview does not include ASI plugins and disables multi-frame-generation unlock settings.

The source links identify the inputs for this preview. They are not a substitute for preparing corresponding source and the complete notices before public redistribution.
