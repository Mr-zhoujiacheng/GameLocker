## 附：GameLocker 独有、MiniDock 没有的能力

对照时容易被忽略的反向差异（这些不是缺口）：

- 游戏启动与存档备份（本地 + 天翼云/百度网盘）
- 内置插帧后端（LSFG / XeSS FG）、OptiScaler 管理
- CPU 功耗与睿频控制、电源方案、锁帧
- 屏幕翻译（OCR）、性能悬浮条、系统屏幕键盘
- 磁贴分组 / 抽屉 / 壁纸 / 媒体控制 / 前台应用监控
- 开始菜单替代（Win 键接管、开始按钮覆盖窗）
- 底栏自动收编"未固定但正在运行"的程序（窗口出现即加、窗口关闭即移除，固定项常驻）

## 若要补齐，建议优先级

> 下表是 2026-11-17 早先列出的缺口；P1/P2 项（窗口预览、文件夹/网址、电池健康、运行指示样式）当天已补齐，是否仍缺以正文状态列为准。

| 优先级 | 项目 | 理由 |
|---|---|---|
| P1 | 窗口预览（DWM 缩略图） | 底栏从"图标条"变成"窗口切换器"，体验增益最大 |
| P1 | 固定项支持文件夹 / 网址 | 工作量小，复用现有 `LaunchItem` 即可 |
| P2 | 电池健康（WMI） | 独立模块，不影响别处 |
| P2 | 运行指示样式可调 | 小改动 |
| P3 | 多显示器支持 | 中等工作量，需重构定位与占位 |
| P3 | 应用组 / 文件夹弧形展开 | 大工作量，需新建弹层体系 |
| — | 控制中心、400KB 体积、Mica 设置窗 | **不建议**：与 WinUI 架构或现有服务冲突 |
